# Solaris web

Vite + React 19 + TypeScript. Two static entry points from one codebase:

| Entry | URL | App component | Owner |
|---|---|---|---|
| `index.html` | `/` (HashRouter: `#/…`) | `src/apps/platform/PlatformApp.tsx` | platform team |
| `demo/index.html` | `/demo/` | `src/apps/demo/DemoApp.tsx` | demo team |

Python models run **in the browser** (Pyodide in a Web Worker). No server.

## Run / build

```bash
npm install
npm run dev          # http://localhost:5180  (predev syncs models + data)
npm run build        # → dist/  (prebuild syncs; runs tsc first)
npm run preview      # serve dist/ on :4180
npm run typecheck
npm run smoke        # headless Playwright check → .screenshots/  (see below)
npm run sync         # re-copy ../models and ../data into public/ manually
```

`dist/` is fully static and uses relative URLs (`base: "./"`), so it works from any host and
any sub-path (`https://x.org/`, `https://x.org/solaris/`, GitHub Pages, S3, `file`-less static
servers). For absolute asset URLs set `VITE_BASE=/solaris/ npm run build`.
Routing is hash-based (`/#/styleguide`), so no SPA fallback/rewrite rules are needed.

## Conventions

- **Styling**: plain CSS, global, class prefix `sol-` (BEM-ish: `.sol-card__title`, `.sol-btn--primary`).
  Use tokens (`var(--sol-…)`) only — no raw hex in components. Feature CSS goes next to the
  feature (e.g. `src/apps/demo/demo.css`, imported by the component) with a feature prefix
  (`.demo-…`, `.plat-…`). Spacing is 4-based; controls are ≥ 44 px.
- **Fonts** are bundled from npm (`@fontsource-variable/newsreader|geist|geist-mono`, SIL OFL) —
  no font CDN. Serif display = `--sol-font-display`, UI = `--sol-font-sans`, numbers = `--sol-font-mono`.
- **Public files**: always build URLs with `publicUrl("data/x.json")` (never `"/data/x.json"`),
  so the site works under a sub-path and from both entries.
- **Links between apps**: `platformUrl("/route")`, `demoUrl()` from `lib/paths.ts`.
- **Honesty** (CONTRACT.md): every number needs a source (`<Stat source=…>` requires it);
  label projections as conditional model outputs (`<Callout tone="honesty">`); Catalyst/Nexus
  get `<Badge tone="new">New</Badge>` / `<Badge tone="info">Simplified model</Badge>`.
- Never return a value from a `useEffect` arrow (`useEffect(() => window.scrollTo(0,0))` crashes:
  Chrome's `scrollTo` now returns a Promise). Use braces.

## Adding a section / route

Platform: add a component under `src/apps/platform/…` and a `<Route>` in `PlatformApp.tsx`
(lazy-load heavy pages with `lazy(() => import(…))`). Keep `/styleguide` and `/dev/runtime`.
Demo: compose sections inside `<main>` in `DemoApp.tsx`; give each `<section>` an `id` and the
`sol-section sol-container` classes for standard rhythm.

Earth hero chapters — replace `PlaceholderHero` with your own:

```tsx
<EarthScroll length={5}>                                   {/* section height in viewports */}
  <EarthChapter range={[0, 0.16]} enter={false} placement="top">…headline…</EarthChapter>
  <EarthChapter range={[0.26, 0.5]} placement="left">…</EarthChapter>
  <EarthChapter range={[0.58, 0.84]} placement="right">…</EarthChapter>
</EarthScroll>
```

- `range` = progress window (0..1); `enter={false}` = visible at load; `exit={false}` = stays to the end.
- `placement`: `top | center | left | right | bottom | bottom-left` (portrait screens stack text at the top).
- Planet choreography: `pathWide` / `pathTall` keyframes `{ at, x, y, d }` (x/y = centre as fraction
  of the stage, d = diameter × min(stage w, h)). Defaults (`DEFAULT_PATH_WIDE/TALL`) are tuned for
  chapters at the ranges above; move both together.
- Custom choreography: `useEarthProgress()` (state, rAF-throttled) or
  `useEarthProgressListener(p => el.style…)` (no re-render) inside `<EarthScroll>`.
- Helper classes for chapter text: `.sol-hero__title` (+ `<span>` gold line), `.sol-hero__lede`,
  `.sol-hero__actions`, `.sol-eyebrow`, `.sol-chapter-title`, `.sol-chapter-text`.
- Reduced motion → static frame, chapters in normal flow, all visible.
- Chapter content stays in the a11y tree; focusing inside a hidden chapter scrolls to it.
- Footer (`<Footer/>`) carries the required NASA SVS imagery credit — keep it on any page with the Earth.

## Model runtime (Pyodide)

```ts
import { getRuntime, useRuntimeStatus, useModelRun, precomputedOrRun, RuntimeError, isAbort } from "../runtime";

const rt = getRuntime();                       // singleton
rt.warmup();                                   // start loading (idempotent) — call early, e.g. after first paint
rt.status;                                     // { state: 'idle'|'loading'|'ready'|'error', stage, step, steps,
                                               //   elapsedMs, timings, modelsAvailable, modelsError, error }
const status = useRuntimeStatus({ warm: true });   // React hook (subscribes)

const r = await rt.run<AerosResult>("aeros", payload, { signal, latest: "aeros-slider" });
//   → solaris_models.api.dispatch("aeros", payload); JSON in / JSON out (NaN → null, numpy → lists)
//   signal: abort → rejects immediately (queued job dropped; a running Python call can't be
//           interrupted, its result is discarded)
//   latest: coalescing key — a newer job with the same key cancels older *queued* ones (sliders)
await rt.call("module.path", "fn", [arg1, arg2]);  // any Python function, args/result JSON

const { result, error, running, ms, run } = useModelRun<AerosResult>("aeros");  // supersedes previous runs

try { … } catch (e) {
  if (isAbort(e)) return;                      // cancelled/superseded, not a failure
  (e as RuntimeError).info.message;            // last line of the Python traceback
  (e as RuntimeError).info.traceback;          // full traceback
}
```

- Jobs run one at a time (FIFO) in a module Web Worker (`runtime/worker.ts`).
- Load sequence (status stages): download Pyodide → `loadPackage(["numpy","scipy"])` → fetch
  `py/manifest.json`, write every listed `.py` into `/home/pyodide/<pkg>/…`, auto-load any extra
  packages they import (`loadPackagesFromImports`), check `import solaris_models.api`.
- Version + URLs: `src/runtime/config.ts` — `PYODIDE_VERSION = "0.29.5"` (Python 3.13.2, numpy
  2.2.5, scipy 1.14.1), `PYODIDE_BASE_URL` (jsDelivr), `PYODIDE_PACKAGES`.
- Model result typing: `ModelResultBase` (model, version, inputs, warnings, provenance, runtime_ms);
  model-specific shapes are documented in `../models/API.md`.
- Dev/test page: `#/dev/runtime` — self-test (numpy/scipy, JSON bridge, traceback) and a manual
  `dispatch` runner pre-filled with the first bundled station.

**Precomputed results** (`../data/precomputed/<model>/<key>.json` → `public/precomputed/…`):
`fetchPrecomputed(model, key)` → result or `null`; `precomputedOrRun(model, key, payload)` →
`{ result, source: "precomputed" | "live" }` — label the source honestly in the UI.

### Self-hosting Pyodide (offline / conference Wi-Fi fallback)

```bash
curl -LO https://github.com/pyodide/pyodide/releases/download/0.29.5/pyodide-0.29.5.tar.bz2
tar xjf pyodide-0.29.5.tar.bz2      # → pyodide/
# Minimal set: copy into web/public/pyodide/
#   pyodide.mjs pyodide.asm.js pyodide.asm.wasm python_stdlib.zip pyodide-lock.json
#   + the numpy-*.whl, scipy-*.whl (and their deps listed in pyodide-lock.json, e.g. openblas)
```

Then set `PYODIDE_BASE_URL = "pyodide/"` in `src/runtime/config.ts` (relative paths resolve
against the site root) and rebuild. Size ≈ 30–40 MB for the minimal set.

## Data

`scripts/sync-data.mjs` copies (all optional; missing files are skipped):

| From `../data/` | To `public/` | Loader |
|---|---|---|
| `stations/stations_bundle.json` | `data/stations_bundle.json` | `loadStationsBundle(): StationsBundle` |
| `co2/co2_bundle.json` | `data/co2_bundle.json` | `loadCo2Bundle(): Co2Bundle` |
| `*.zip|*.csv` in `./`, `stations/`, `co2/`, `downloads/` | `data/downloads/` | `loadDataAvailability().downloads` |
| `stations/csv/*.csv` | `data/stations-csv/<id>.csv` | `availability.stationCsvDir` |
| `precomputed/**` | `precomputed/**` | `fetchPrecomputed` |

Helpers: `stationSeason(station, "D-J-F")`, `seasonLabel(station, season)` (handles the southern
hemisphere flip), `toPoints`, `yearRange`, `findStation`.

CSV: `parseAerosCsv(text)` / `parseAerosFile(file)` → `{ series: { years, "D-J-F", "J-J-A" } | null,
messages: {level, message, line?}[], counts, ok }`. Accepts `YEAR,D-J-F,J-J-A` (aliases
Year/DJF/JJA), NASA `station.csv` (999.9 = missing, extra columns ignored), `,`/`;`/tab, quotes, BOM.
Export: `toCsv(rows, columns, comments)`, `seriesToCsv({ year, mean, lower, upper }, comments)`,
`downloadText(filename, text)`.

## Charts (`src/components/charts`)

```tsx
<TimeSeriesChart
  title="Washington D.C. · winter (D-J-F)"  unit="°C"  projectionStart={2026}
  series={[
    { id: "obs",   label: "Observed",     role: "observed",   type: "points", data: [{ x, y }] },
    { id: "trend", label: "Fitted trend", role: "trend",      data },           // dashed by default
    { id: "proj",  label: "Aeros 4.0",    role: "projection", data: [{ x, y, lower, upper }], bandLabel: "95% range" },
  ]}
  footer="Source: … · Conditional model output"
/>
```

Props: `series` (`type: line|points|line+points|band`, `role`, `color`, `dashed`, `bandLabel`,
`hideInLegend`, `hideInTooltip`), `unit`, `yLabel`, `projectionStart`, `projectionLabel`,
`markers[{x,label}]`, `references[{y,label}]`, `xDomain`, `yDomain`, `includeZero`, `height`
(default responsive), `digits`, `legend` (clickable toggles), `animationMs` (tween on data change),
`description` (screen readers), `footer`, `formatX`. Crosshair: mouse, touch drag, ←/→/Home/End.

`<GroupCompareChart groups={[{label, value, lower, upper, note, color}]} unit reference={0} digits ciLabel />`
— dot + CI rows (urban vs rural, countries, periods). `<Sparkline data={number[] | {x,y,lower,upper}[]} band label />`.
Colours: `CHART_COLORS`, `SERIES_PALETTE`, `MODEL_COLORS` → token CSS variables (Okabe–Ito derived).

## Smoke test

`npm run smoke` starts Vite on a free port (or `-- --preview` for `dist/`, or `SMOKE_URL=…`),
loads `/`, `/demo/`, `#/styleguide`, `#/dev/runtime` at 1440×900 and 390×844@3x, plus a
reduced-motion pass. Fails on console errors, page errors, 4xx/5xx same-origin requests, or
horizontal overflow; waits for the Pyodide self-test. Screenshots → `.screenshots/`.
`--only=home,demo` runs a subset; `--no-runtime` skips Pyodide. Add checks to `CHECKS` in
`scripts/smoke.mjs`.
